How can a society extend beyond personal acquaintance, and what makes cooperation stable? This repository begins by separating network reach, overlapping membership, trust, and incentives in a small, fully checked model.

The current package proves that a two-neighbor contact bound permits an unbounded connected population, constructs overlapping memberships, and gives an exact cost-versus-sanction condition for stable mutual contribution. The distinction matters: contact structure, common identity, and incentive compatibility are different mathematical objects.
